# Canada CRS Score Dashboard

Live page: https://lylaminju.github.io/crs-dashboard/

A static, one-page dashboard for exploring Canada Express Entry Comprehensive Ranking System (CRS) scores.

Features:

- Adjust core CRS factors.
- View the total score and breakdown.
- Compare score opportunities.
- Switch to a polygon view of major factor groups.
- Open related official Canada.ca source links from factor titles.

Efficiency features:

- Use one-click desktop controls for factors such as age and skilled work years instead of repeatedly opening dropdowns.
- See score increases and decreases through temporary color and arrow feedback when factor scores change.
- Review future score opportunities with projected point changes.
- Use the polygon view to scan major CRS factor groups at once.

The calculator logic and labels are based on the official Canada.ca CRS calculator and criteria pages:

- [Canada.ca - Express Entry: Check your score](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/express-entry/check-score.html)
- [Canada.ca - Comprehensive Ranking System criteria](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/express-entry/check-score/crs-criteria.html)

This project is plain static HTML, CSS, and JavaScript. No build step is required.
